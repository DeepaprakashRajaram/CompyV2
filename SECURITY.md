# Security Policy

## Supported Versions

Currently, Compsognathus (Compy) V2 is in active development. There are no production-ready supported versions at this time.

## Reporting a Vulnerability

We take the security of Compy and its users seriously. If you discover a security vulnerability, please follow responsible disclosure practices.

Do NOT open a public GitHub issue for security vulnerabilities. Instead, please contact the repository maintainers privately to report any issues. 

Please provide:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and risk assessment.

We will acknowledge receipt of your vulnerability report and strive to address the issue promptly.
