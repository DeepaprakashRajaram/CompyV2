17. Digital Forensics Reference Glossary LEGAL & TECHNICAL

Fileless Malware: Malicious software that operates entirely within volatile computer memory (RAM) or native OS scripting interpreters, without storing permanent binary files on the hard drive.

VAD (Virtual Address Descriptor): A self-balancing binary tree structure utilized by the Windows memory manager to track memory allocation and protection states for every process.

DKOM (Direct Kernel Object Manipulation): A sophisticated rootkit technique where malware directly modifies kernel memory objects (such as unlinking an EPROCESS from ActiveProcessLinks) to conceal its execution.

Process Hollowing: A code injection method where an attacker spawns a legitimate process in a suspended state, hollows out its legitimate memory sections, and replaces them with an encrypted malicious payload.

PAGE_EXECUTE_READWRITE (RWX): A memory page permission granting simultaneous write and execution rights. High-fidelity forensic indicator of shellcode unpacking and self-modifying code.

PPID Spoofing: The manipulation of a newly created process's parent process metadata to make it appear as an illegitimate child of a trusted Windows daemon (e.g., spoolsv.exe or services.exe).

Reflective DLL Injection: A technique whereby a dynamic link library is injected into a target process's memory space directly from volatile memory buffers, completely bypassing the Windows operating system loader.

Memory Smear: Inconsistencies introduced during physical RAM acquisition due to running CPU threads modifying memory pages while the imaging tool is reading them.

Tri-State Forensic Logic: Deterministic three-valued logic system (TRUE / FALSE / UNKNOWN) ensuring that forensic conclusions distinguish between verified absence of malware and lack of investigative telemetry.

Statutory Certification / Legal Admissibility: Formal certification under relevant jurisdiction rules (e.g., Section 65B, FRE 902) requiring execution by qualified personnel certifying acquisition provenance, tool validation, and evidence integrity.
